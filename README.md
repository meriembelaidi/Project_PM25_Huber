Project Description:
This project focuses on analyzing PM2.5 air pollution data using statistical methods, data visualization and Huber Regression to study pollution patterns and build a robust predictive model.

Objectives:
Explore and clean the dataset
Analyze PM2.5 concentrations
Detect outliers and missing values
Study correlations between variables
Apply Huber Regression
Evaluate model performance

Technologies:
Python
Pandas & Numpy
Matplotlib & Seaborn
Scikit-learn
Statsmodels

Run the Python script:
python Project_PM25.py
